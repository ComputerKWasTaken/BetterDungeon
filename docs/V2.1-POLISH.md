# v2.1 polish verification

The v2.1 polish pass removes the Android narrator (including its native bridge),
moves Adventure Notes into the shared popup, softens the What's New panel, and
corrects Android input history and Command sub-mode controls.

Run `./build.ps1 all` for repository smoke checks, extension ZIP, Android unit tests,
and debug APK. Push to `dev` for the same GitHub quality gate and downloadable
artifacts. Promote only after reviewing the changes.

## Manual review before stable

- Browser and Android: complete the provider and feature checks in [AI setup and routing](AI.md#verification-before-stable). AI settings now live in the dedicated AI tab; the Ultrascripts switch controls script access only.

- Browser and Android: open an adventure, open the BetterDungeon popup, and type
  into Adventure Notes. Reopen the popup and switch between adventures to verify
  persistence and isolation. Confirm the editor is disabled outside an adventure.
- Browser and Android: expand/collapse What's New and change release tabs. Check
  narrow layouts, keyboard focus, and reduced-motion settings.
- Android: type a multiline action with the software keyboard. Newlines must not
  add history entries. Tap Submit action; the sent action should appear once in
  history, with the previous/next controls restoring it.
- Android: enter Command mode and cycle Standard, Subtle, and OOC with the buttons
  above the input. Verify one step per tap, keyboard open/closed, and after
  navigating away and returning. The mode menu should still scroll on narrow screens.
- Android settings: confirm the caret stabilization control is present and narrator/voice controls are absent.

The smoke checks do not establish pixel-perfect rendering or behavior on a
physical device. This checklist is the product-level release check; browser
automation and live AI Dungeon requests are intentionally kept out of CI.
