# v2.1 polish verification

The September 8 polish pass removes the Android narrator (including its native
bridge), aligns Notes with native Plot Components, softens the What's New panel,
and corrects Android input history and Command sub-mode controls.

Run `./build.ps1 all` for repository smoke checks, extension ZIP, Android unit tests,
and debug APK. Push to `dev` for the same GitHub quality gate and downloadable
artifacts. Promote only after reviewing the changes.

## Manual review before stable

- Browser and Android: open Plot Components with Plot Essentials visible. Compare
  Notes heading, background, padding, and editor typography. Type notes, switch
  adventures, and return to verify persistence and isolation.
- Browser and Android: expand/collapse What's New and change release tabs. Check
  narrow layouts, keyboard focus, and reduced-motion settings.
- Android: type a multiline action with the software keyboard. Newlines must not
  add history entries. Tap Submit action; the sent action should appear once in
  history, with the previous/next controls restoring it.
- Android: enter Command mode and cycle Standard, Subtle, and OOC with the buttons
  above the input. Verify one step per tap, keyboard open/closed, and after
  navigating away and returning. The mode menu should still scroll on narrow screens.
- Android settings: confirm the narrator toggle and voice controls are absent.

The deterministic tests do not establish pixel-perfect rendering or behavior on
a physical device. This checklist is a manual release check; no browser automation
or live AI Dungeon requests are added to CI.
